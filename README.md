# TOP-recipes-project

This is an exploratory project for learning the basics of web development. I practiced constructing the
file structure of a website, creating the HTML boilerplate, and using different tags to get the desired
effect on my webpage. I completed most of this through Git, improving my command line skills along the 
way.

In terms of this project, while I'm happy of what I accomplished, I see so much room for improvement. 
I'm excited to begin teaching myself CSS in order to make my websites actually look good, but I'm moreso
intrigued by the backend development of it all. I'm very excited to learn how to create full websites that
can autopopulate data and are interactable.

All in all, a good first step in my webdev journey!
